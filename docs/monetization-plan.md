# Avocato 수익화 설계

> **현재 상태 업데이트**: 웹은 완전히 결제 수단 없음(Stripe 제거됨),
> Pro 구독은 애플 IAP로만 판매. 이 문서 아래 내용 중 "웹 구독", "Stripe
> 웹훅" 언급은 이제 실제 구조와 다름 — 히스토리/아이디어 참고용으로만
> 보고, 현재 진짜 상태는 `docs/ios-storekit-setup.md`와
> `docs/app-store-listing.md` 기준으로 봐주세요.

경쟁 앱 조사(Just the Recipe, Peel, Pluck 등)에서 검증된 패턴 기준으로
설계. 원칙: **무료로 충분히 반하게 만들고, 가장 비싼 기능(영상 추출)에
한도를 걸어 구독으로 전환**시킨다.

## 검증된 시장 데이터 (조사 요약)

- Peel: 웹 레시피 무료 무제한, **영상 추출만 유료** ($2.99/mo, $49.99 평생)
- Pluck: 무료 월 3회, $2.99~11.99/mo, $299.99 평생
- Just the Recipe: 다운로드 8.2만, Food & Drink 상위 100 — 시장 수요 검증
- 수렴 가격대: **월 $3~8, 연 $29~50, 평생 $49~99**

## 단계별 계획

### Phase 0 — 지금 (출시 ~ 첫 유저)

전부 무료, 결제 없음. 목표는 리뷰·다운로드·사용 데이터.
Vercel Analytics로 어떤 소스(유튜브/틱톡/사진)가 많이 쓰이는지 관찰.

### Phase 1 — 유저가 생기면 (다운로드 ~500+ 또는 API 비용이 부담될 때)

무료 한도 도입 + Pro 구독:

| | 무료 | Pro |
| --- | --- | --- |
| 영상 링크 추출 (유튜브·틱톡·인스타) | **주 3회** | 무제한 |
| 사진·스크린샷·PDF·텍스트 | 무제한 | 무제한 |
| 쿡 모드, 타이머, 테마, 공유 | 전부 포함 | 전부 포함 |
| 레시피 클라우드 저장/동기화 (추후) | — | 포함 |

> 영상 추출만 거는 이유: AI 비용이 가장 큰 경로이자 경쟁 앱들이
> 검증한 "돈 내는 기능". 사진·텍스트를 무료 무제한으로 두면 앱을
> 지우지 않고 계속 쓰다가 전환됨.

### 가격 (영어권 타겟 — USD 기준, 타 통화는 애플 자동 환산)

| 상품 | 가격 | Product ID |
| --- | --- | --- |
| Pro 월간 | $3.99 | `avocato.pro.monthly` |
| Pro 연간 | $29.99 (월 $2.50 꼴 — 메인으로 밀기) | `avocato.pro.yearly` |
| 평생 (출시 기념 한정) | $49.99 | `avocato.pro.lifetime` |

- 연간에 **7일 무료 체험** 붙이기 (전환율 가장 높은 조합)
- Apple Small Business Program 신청 → 수수료 30%가 아닌 **15%**

### Phase 2 — 확장 (Pro 안착 후)

- 클라우드 저장·기기 간 동기화 (Supabase 이미 준비됨 — profiles/saved_recipes 테이블 존재)
- 장보기 리스트, 주간 식단 → Pro 가치 강화
- 웹 구독은 Stripe 유지 (웹에서 결제하면 앱에서도 Pro — reader 규정상 앱 안에서 웹 결제 언급만 안 하면 됨)

## 기술 구현 (Phase 1 때)

1. **RevenueCat** 사용 (`@revenuecat/purchases-capacitor`)
   - StoreKit 직접 구현 대비 영수증 검증·구독 상태 관리·복원을 다 해줌
   - 월 매출 $2,500까지 무료 — 초기엔 비용 0
2. App Store Connect에서 위 Product ID 3개 생성
3. RevenueCat webhook → Supabase `profiles.plan` 갱신 (기존 Stripe webhook 패턴 재사용)
4. 게이팅: 기존 `PaywallGate` 컴포넌트 + `consumeQuota` 로직 부활 (지금은 꺼져 있을 뿐 코드가 남아 있음)
5. 페이월 화면: 추출 한도 소진 시점에 노출 (앱 시작 시 노출 금지 — 심사+전환율 둘 다 나쁨)

## 하지 말 것

- 출시 직후 결제부터 붙이기 (리뷰 0개 상태에서 페이월 = 삭제 직행)
- 광고 (CookNotebook이 이걸로 평점 망함)
- 앱 안에서 Stripe/외부 결제 링크 노출 (가이드라인 3.1.1 — 이미 숨김 처리됨, 유지)
